## 🌟 Key Features

### 1. 🎨 12 Unique Presentation Layout Archetypes (Zero Duplication)
Unlike conventional CV makers that merely change colors over the exact same layout, each template here features a **genuinely distinct architectural structure**, ensuring all text and blocks maintain a clean 20px–28mm breathing margin from borders:
1. 📐 **Modern Left Sidebar**: Bold tinted left sidebar (74mm) with avatar, contact info, and skill meters; clean white right column for work history.
2. 📑 **Elegant Right Sidebar**: Left column takes prime focus on career milestones and education; soft-tinted right column hosts secondary details.
3. 🏷️ **Hero Banner Top**: Full-width bold top header banner with large avatar, name, and contact chips; 60/40 two-column body below.
4. 🇨🇭 **Swiss Clean ATS**: Ultra-clean hairline rules, expansive 28mm whitespace, highest ATS automated parser compatibility.
5. ⏳ **Continuous Timeline**: Unbroken vertical milestone line connecting career progress and education with glowing indicator dots.
6. 🍱 **Modern Bento Grid**: Modular rounded card containers inspired by Bento UI, organizing each section into a standalone visual unit.
7. 👑 **Executive Serif Classic**: Double framed border, centered classical serif nameplate, tailored for directors, executives, and senior consultants.
8. 📊 **Compact 3-Column**: Slim header band with 3 dense, balanced parallel columns below.
9. 📰 **Editorial Magazine**: Bold oversize typography, stylish pull-quote summary callout box, asymmetrical creative layout.
10. 🌓 **Dual Contrast Split 50/50**: Two balanced half panels with soft contrasting background, perfectly partitioned.
11. ⚙️ **Technical Grid**: Subtle technical gridlines, specification badges, monospace/clean sans typography for engineers & developers.
12. 🏛️ **Framed Border Deluxe**: Elegant double-line margin frame with decorative corner accents.

---

### 2. 🌈 Dynamic Theme Color Engine
* Apply ANY primary theme color to ANY layout with 1 click:
  * 12 recruitment-ready color presets: Navy Blue, Tech Cyan, Emerald Green, Burgundy Red, Slate Charcoal, Creative Purple, Amber Orange, Rose Pink, Elegant Teal, Bronze Earth, Neutral Gray, Midnight Black.
  * Custom HTML5 `<input type="color">` selector for any bespoke brand palette.
  * Automatic real-time generation of complementary gradients, soft background tints, and harmonious borders.

---

### 3. ↔️ Draggable Form Editor Resizer
* Drag the divider between the form editor and preview canvas to freely adjust width from **400px to 850px**.
* Comfortably edit extensive project bullets without cramped text fields.
* Auto-persists your preferred width to `localStorage`. Double-click to reset to 530px default.

---

### 5. 💾 Proprietary `.dungauto` File Format & LocalStorage Auto-Sync
* **Auto-Save**: Changes made in the editor automatically synchronize to browser `localStorage` in real-time.
* **`.dungauto` Profile File**:
  * Export complete profile state with one click as `CV_[FullName].dungauto`.
  * Import any `.dungauto` file on any computer to instantly reload your exact data, active template, chosen theme color, and section settings.

---

### 6. 🖨️ High-Resolution Vector A4 Print & PDF Generation
* **Direct Vector Print (`window.print()`)**: Configured with `@page { size: A4 portrait; margin: 0; }` for crisp, selectable text and 100% ATS-friendly parsing.
* **1-Click PDF Download (`html2pdf.js`)**: Instant client-side download without server dependencies.
* **Live Preview Stage**: Zoom in, zoom out, or fit to screen effortlessly.

## 🚀 Quick Start Guide

### Option 1: Live Web App (GitHub Pages)
Visit directly: **[https://dungautomation-dev.github.io/curriculum-vitae/](https://dungautomation-dev.github.io/curriculum-vitae/)**

### Option 2: Local Windows 1-Click Launcher
1. Clone this repository:
   ```bash
   git clone https://github.com/Dungautomation-dev/curriculum-vitae.git
   cd curriculum-vitae
   ```
2. Double click **`Run_Curriculum_Vitae.bat`**.
3. Select `[1]` to launch immediately in your default browser.
