## 🌟 Key Features

### 1. 🗂️ 100 Multi-Industry CV Templates (10 Sectors × 10 Layouts)
Built upon a dynamic design matrix pairing 10 major industry color schemes with 10 structural layout archetypes:
* ⚡ **Electrical & Engineering**: Blueprint Pro, M&E Contractor, Industrial Tech, Automation Leader...
* 💻 **Information Technology & Software**: Terminal Developer, Fullstack Modern, DevOps Matrix...
* 📈 **Sales & Business Development**: High Conversion, B2B Enterprise, Key Account Executive...
* 📢 **Marketing & Communications**: Creative Growth, Brand Strategist, Digital Social...
* 💰 **Finance & Banking**: Wall Street Navy, Audit Precision, Investment Analyst...
* 🏥 **Healthcare & Medical**: Clinical Clean, Pharma Specialist, Medical Doctor...
* 🎓 **Education & Academia**: Academic Classic, Lecturer Profile, Cambridge Scholar...
* 🎨 **Design & Creative Arts**: Swiss Minimal, Creative Grid, Portfolio Showcase...
* 🛎️ **Hospitality & Culinary**: 5-Star Luxury, Tourism Director, Gourmet Master...
* 🤝 **Human Resources & Management**: People First, HR Generalist, Talent Acquisition...

The builder loads immediately with authentic, comprehensive data for a Senior Electrical Engineer:

---

### 3. 📝 Comprehensive Mandatory & Modular Sections
* 📌 **Core Mandatory Sections**:
  * Summary / Objective
  * Personal Information (Full name, title, contact details, links, photo)
  * Education
  * Soft Skills
  * Work Experience
* 🎯 **Advanced Modular Sections**:
  * Hard Skills with **3 display rating modes**: Percentage (%), 5-Star rating (⭐), or Bullet Dots (•).
  * Key Strengths & Core Competencies
  * Hobbies & Interests
  * Key Projects & Impact
  * Professional Certifications
  * Language Proficiencies
  * References & Testimonials
  * Honors & Awards
* 💡 **Quick-Pick Selection Pills**: One-click pills to quickly inject common skills, traits, and hobbies without typing.

---

### 4. 💾 Proprietary `.dungauto` File Format & LocalStorage Auto-Sync
* **Auto-Save**: Changes made in the editor automatically synchronize to browser `localStorage` in real-time.
* **`.dungauto` Profile File**:
  * Export complete profile state with one click as `CV_[FullName].dungauto`.
  * Import any `.dungauto` file on any computer to instantly reload your exact data, active template, and section settings.

---

### 5. 🖨️ High-Resolution Vector A4 Print & PDF Generation
* **Direct Vector Print (`window.print()`)**: Configured with `@page { size: A4 portrait; margin: 0; }` for crisp, selectable text and 100% ATS-friendly parsing.
* **1-Click PDF Download (`html2pdf.js`)**: Instant client-side download without server dependencies.
* **Live Preview Stage**: Zoom in, zoom out, or fit to screen effortlessly.

## 🚀 Quick Start Guide

### Option 1: Live Web App (GitHub Pages)
Visit directly: **[https://dungautomation-dev.github.io/curriculum-vitae/](https://dungautomation-dev.github.io/curriculum-vitae/)**

### Option 2: Local Windows 1-Click Launcher
1. Clone this repository:
   ```bash
   git clone https://github.com/Dungautomation-dev/curriculum-vitae.git
   cd curriculum-vitae
   ```
2. Double click **`Run_Curriculum_Vitae.bat`**.
3. Select `[1]` to launch immediately in your default browser.
